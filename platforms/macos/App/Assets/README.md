# Remap application icon

The 1024-pixel PNG is the source for the generated `.icns` bundle asset.
Remap's typed app packager derives every required macOS representation.

The source was generated with the built-in OpenAI image generator on
2026-08-16 from this production prompt:

> Create a distinctive macOS icon for Remap, a power-user utility that maps an
> arbitrary name or place to a different address or service. Show two precise
> offset spatial planes with one clean directional transformation from x to y.
> Use deep graphite with one cobalt-to-teal accent, restrained dimensional
> geometry, subtle tactile material, and a bold silhouette that survives at 16
> pixels. No text, logos, map pin, chain link, fantasy doorway, watermark, or
> tiny interface elements.

The icon is an original project asset. It is distributed under the repository's
Apache-2.0 license.
